# EVA2027-LLM-Judge

Evaluation prompts for studying LLM-judge reliability in user-interruption handling by full-duplex spoken dialogue models.

## Evaluation Prompts

The following evaluation rubrics were used in our study:

- [Original FDB Rubric](original_fdb_rubric.md) — Adopted from [Full-Duplex-Bench](https://github.com/DanielLin94144/Full-Duplex-Bench).
- [Intent-Aware Rubric](intent_aware_rubric.md) — Proposed in our study to assess adherence to the currently applicable user instruction.
